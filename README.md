CCTV Surveillance System Replacement – Super Market

Project Overview

I replaced the existing CCTV surveillance system at Super Market with new cameras, a network switch, and a Network Video Recorder (NVR).

I installed and configured the new NVR, installed a regular Ethernet switch, and set up local and remote camera viewing. The replacement was completed without recovering the forgotten password from the old system.

This project demonstrates practical experience with hardware replacement, network connectivity, CCTV installation, and NVR configuration.

## Project Objectives

- Replace the existing CCTV system.
- Install new surveillance cameras.
- Install a network switch to connect the system.
- Install and configure the NVR.
- Enable local and remote camera viewing.

## Work Completed

1. Replaced the old CCTV system with new equipment.
2. Installed new surveillance cameras.
3. Installed a regular Ethernet network switch.
4. Installed and configured the NVR.
5. Set up local and remote viewing of the cameras.
6. Completed the replacement without recovering the old system's password.

## Skills Demonstrated

- Hardware installation and replacement
- Basic network connectivity
- Ethernet switching
- NVR installation and configuration
- CCTV system setup
- Local and remote surveillance viewing
- Practical IT troubleshooting

## Project Outcome

The market's old CCTV system was replaced with a new surveillance system supporting local and remote viewing.
